# ECG Mastery

A premium bilingual (English / Dutch) ECG education platform for physicians: a competency-based
curriculum from basic rhythm recognition to expert clinical reasoning, built on real recordings from
the open PTB-XL dataset and on physiologically modelled synthetic tracings.

## Quick start

```bash
npm install
npm run dev          # http://localhost:3000 → redirects to /en or /nl
```

Other scripts:

| Script | Purpose |
| --- | --- |
| `npm run build` / `npm start` | Production build (fully static pages) and server |
| `npm run typecheck` | Strict TypeScript check |
| `npm test` | Unit tests: synthesizer physiology, codec, scoring, content integrity |
| `npm run lint` | ESLint (Next.js core-web-vitals + TypeScript) |
| `npm run content:check` | Editorial status report (medical review + Dutch translation) per content item |
| `npm run ecg:fetch-ptbxl` | Re-download the curated PTB-XL subset from PhysioNet into `public/ecg/ptbxl` |

## What is in the box

- **Curriculum** — 10 modules, 20 lessons, 4 levels (Foundation → Expert), each lesson with explicit
  learning objectives tagged to competencies, guideline references and an in-lesson check.
- **Interactive cases** — history → structured interpretation scored against an expert key →
  management question → outcome and teaching points.
- **ECG library** — 32 real PTB-XL recordings (human-validated, artefact-free) and 40 synthetic
  tracings, each with a structured interpretation key, teaching points and provenance.
- **Assessments** — formative practice sets per module (immediate feedback) and summative module
  tests with a pass mark.
- **Progress** — competency mastery computed from question and interpretation scores with recency
  weighting; stored locally, with a repository seam for a server backend.
- **ECG viewer** — SVG rendering at true 25 mm/s and 10 mm/mV, 3×4 (+ rhythm strip), 6×2 and single-lead
  layouts, calipers (ms / bpm / mV), zoom, focus leads, annotations, light and dark paper.
- **ECG synthesizer** — a 3-D cardiac dipole model projected onto the 12 leads, with a rhythm engine
  (sinus, AF, flutter, AV blocks, ectopy, SVT, VT, pacing) and morphology presets (bundle branch blocks,
  hypertrophy, STEMI by territory, pericarditis, electrolytes, long QT, Brugada, WPW).

See `docs/ARCHITECTURE.md`, `docs/CONTENT-AUTHORING.md` and `docs/ECG-DATA.md`.

## Editorial and medical review

Every content item carries two independent review records — medical accuracy of the English source
and fidelity of the Dutch translation — plus the source version the translation was made from.
All content in this repository is currently **authored, not yet signed off**: medical review is
`in-review` and Dutch translations are `draft`. Run `npm run content:check` for the full report.
